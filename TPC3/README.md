## **Corrida para o 100:**

Este trabalho tem como objetivo consolidar o domínio das estruturas de controlo fundamentais em Python (while, if, elif, else) através da implementação do jogo "Corrida para o 100". Este é composto por duas vertentes distintas: uma em que o utilizador joga em primeiro lugar e outra em que é o computador a iniciar o jogo.

A lógica do jogo assenta na implementação de uma estratégia matemática em que, ao fim de cada jogada, a CPU avalia a soma atualizada através do operador módulo (soma % 11). Este cálculo permite ao computador determinar o valor exato a jogar para atingir a sequência de números-chave (1, 12, 23, 34, 45, 56, 67, 78, 89, 100) e garantir a vitória. Adicionalmente, o programa assegura uma validação rigorosa dos dados de entrada, prevenindo erros de execução ao limitar as escolhas ao intervalo de 1 a 10.

Relativamente ao trabalho anterior onde enfrentei mais dificuldades no controlo das diversas estruturas, neste projeto notei uma evolução clara na gestão dos fluxos de repetição e condicionais.

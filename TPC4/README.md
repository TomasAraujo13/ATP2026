## **Aplicação para manipulação de listas de inteiros**

O objetivo principal deste trabalho consistiu no desenvolvimento de uma aplicação interativa em Python, baseada num menu de opções, dedicada à manipulação de listas de números inteiros. A aplicação foi desenvolvida para permitir ao utilizador gerir uma lista interna de dados através de várias funcionalidades essenciais: criar listas automáticas (com números aleatórios) ou manuais, calcular a soma e a média dos elementos, determinar o maior e o menor valor, verificar se a lista se encontra ordenada por ordem crescente ou decrescente, procurar elementos específicos e, por fim, encerrar o programa apresentando o estado final da lista.   
A etapa que senti mais dificuldades e exigiu um raciocínio lógico mais avançado foi a programação da opção 9 (procurar um elemento). O desafio consistiu em implementar a regra de devolver a posição exata do número na lista (tendo em conta que a contagem de índices em Python começa no zero) ou devolver o valor -1 caso o elemento não estivesse presente na lista.
